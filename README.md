# 📸 Photography Sidebar Website

A responsive **photography-themed sidebar website** built using **pure HTML and CSS**, featuring a toggleable sidebar menu created without JavaScript.

This project focuses on layout design, CSS transitions, and UI structure using modern frontend practices.
